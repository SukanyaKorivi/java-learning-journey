internally 2D arrays are stored as 1D array of 1D arrays meaning the reference variable to stored on stack pointing to the top of actual array object. 
now in heap the array storage is divided into 2 layers such that layer 1 consists of fixed size (rows) 1D array 
which again stores the references to the completely seperate independent arrays(column arrays) in which the actual int data is stored. 
As the column arrays are stored as independent 1D arrays , java supports jagged arrays
